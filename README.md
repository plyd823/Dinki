**Dinki**
---
`Dinki` is the ultimate practice tool for Mad Max speedrunning

*GOG build*

The GOG exe built 2015-12-01 is recognized automatically and uses a separate core that finds what it needs at runtime. On it the menu, rebinding and the watches overlay (including health, position, velocity and vehicle health) work; noclip, position save/load and the spawner are Steam-only for now. Everything it finds is written to `mm_log.txt`.

*Controls*

Most keys below can be changed in the in-game menu (the spawner key can't yet). Changes are saved to `dinki.ini` next to `dinki.asi`.

`INSERT` - Open the Dinki menu (rebind keys)

`RSHIFT` - toggle no clip state 

  `F1` - set fly speed to 10
  
  `F2` - set fly speed to 100
  
  `F3` - set fly speed to 200
  
  `F4` - set fly speed to 300
  
  `F5` - set fly speed to 400

  
`Space` - fly up during no clip state

`LSHIFT` - fly down during no clip state


`F9` - Save Position

`F10` - Load Position


`F12` - Show / hide the watches overlay (choose which values it shows, and its text size, in the menu)


`RSLASH` - Open Spawner Menu
