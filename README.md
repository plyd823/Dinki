**Dinki**
---
`Dinki` is the ultimate practice tool for Mad Max speedrunning

*Controls*
`RSHIFT` - toggle no clip state
  `F1` - set fly speed to 10
  `F2` - set fly speed to 100
  `F3` - set fly speed to 200
  `F4` - set fly speed to 300
  `F5` - set fly speed to 400
`Space` - fly up during no clip state
`LSHIFT` - fly down during no clip state

`F9` - Save Position
`F10` - Load Position

`RSLASH` - Open Spawner Menu
